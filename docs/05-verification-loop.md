# 验证闭环

Agent 完成任务时，默认执行以下闭环：

```text
理解需求
  -> 明确验收标准
  -> 实现最小可验证改动
  -> 构建
  -> 运行相关测试
  -> 检查正常、边界、异常路径
  -> 记录证据
  -> 更新状态文件
```

## 验证优先级

1. 单元测试：纯函数、状态机、解析器、参数校验。
2. 组件测试：服务、持久化、设备适配层、算法管线。
3. 模拟集成：mock server、模拟设备、协议回放、固定样例。
4. 端到端：启动应用并执行关键流程。
5. 人工验证：真实设备、真实环境、视觉检查。

## 替代验证

缺少真实设备、外部服务、授权或数据样本时，不能直接跳过验证。应选择：

- mock。
- 模拟器。
- 协议回放。
- 固定输入输出样例。
- 静态检查。
- 日志检查。

并明确说明仍需真实环境确认的项目。

## 完成说明

完成任务时必须说明：

- 改了哪些文件。
- 运行了哪些命令。
- 哪些验证通过。
- 哪些未验证。
- 使用了哪些替代验证。
- 剩余风险是什么。

验证失败时，不得声称任务完成。
