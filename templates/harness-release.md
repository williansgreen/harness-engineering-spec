## Pre-Release Checks

- Release build succeeds.
- Tests pass.
- Version number is updated.
- Config templates are included.
- Logs and data directories are documented.
- External dependencies are documented.
- Deployment acceptance is recorded in `harness/deployment-acceptance.md` when a package or installed copy is tested.
- Sensitive data and secret handling are checked against `harness/security-data.md`.
- Manual checks and blockers are recorded.
