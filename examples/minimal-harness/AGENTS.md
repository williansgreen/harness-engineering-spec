# Minimal Harness Example

This repository is a documentation-only example used to test the generic harness files.

## Startup Workflow

1. Read this file.
2. Read `feature_list.json`.
3. Read `progress.md`.
4. Read `session-handoff.md`.
5. Run the check command in `harness/test.md`.

## Working Rules

- Keep one active feature at a time.
- Do not mark a feature passing without evidence.
- Update progress and handoff after substantial changes.

## Definition of Done

A change is done when the harness check passes and evidence is recorded in `feature_list.json`.
